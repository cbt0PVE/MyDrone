# PX4 参数清单与失控保护链路

> 规则：每一项都要记录 **旧值 / 新值 / 依据 / 回退**。默认值以你机上的 QGC 参数页为准（不同 PX4 版本默认值有差异），下表"默认"列仅供对照。

## 1. 目标参数表

| 参数 | 目标值 | 作用 | 状态 |
| --- | --- | --- | --- |
| `RC_MAP_OFFB_SW` | 开关 B 的通道号（如 6） | 把该拨杆映射为 Offboard 模式开关 | ⏳ 等通道映射结果 |
| `COM_RC_OVERRIDE` | 见下方说明 | 打杆抢权（退出自主/Offboard 交还人工） | ⚠️ 需确认位掩码含义 |
| `RC_STICK_DZ` | 0.10–0.15 | 摇杆零点死区，滤 PPM 抖动 | ⚠️ 默认可能已是 0.1，收益待验证 |
| `COM_RC_IN_MODE` | 0（RC 输入启用） | 之前"禁用遥控器"很可能就是改了这个 | ⏳ 上电核对现值 |
| `COM_OF_LOSS_T` | 1.0 s（默认） | Offboard 数据流丢失多久触发保护 | 建议确认 |
| `COM_OBL_RC_ACT` | 按需（如 0 = Position） | Offboard 中 RC 丢失时的动作 | 建议确认 |
| `COM_RC_LOSS_T` | 0.5 s（默认） | RC 信号丢失判定时间 | 建议确认 |
| `NAV_RCL_ACT` | 按需（如 1 = Hold / 2 = Return） | RC 丢失后的失效保护动作 | 室内建议 Hold/Land，别 Return |
| `COM_DISARM_PRFLT` | 默认 10 s | 地面未解锁自动上锁超时，调试时别调太小 | 注意 |

### 关于 `COM_RC_OVERRIDE`（重要，别想当然）

PX4 新版把它当**位掩码**用，不是简单的 0/1：常见含义是 bit0 = 在 AUTO 模式允许打杆抢权，bit1 = 在 OFFBOARD 模式允许打杆抢权。若你只设 `1`，可能只对 AUTO 生效，**Offboard 下打杆仍然抢不回来**。

- 先查你固件版本的参数说明（QGC 参数页点该参数有描述文本），确认是否需要设成 `3`。
- 相关阈值参数（不同版本叫法不同，如 `COM_RC_STICK_OV`）决定"打多少算打杆"，默认偏大（约 30%），救机时够用，但**小杆量修正不会触发抢权**——这是设计如此，不是 bug。

### 关于 `RC_STICK_DZ`

默认通常已是 0.1（10%）。PPM 抖动一般只有 1–3%，所以调到 0.15 的边际收益很小。
**如果确实在"手不碰杆"时被判定抢权**，优先怀疑：
1. PPM 信号本身质量差（丢帧、通道错位、脉宽漂移）；
2. 遥控器电位器零点偏了（回中后通道值长期偏离 1500）；
3. 模式开关通道冲突（开关 A 的档位与代码期望的模式不一致）。

判断方法：QGC Radio 页静置观察每个通道数值是否稳定；若 Channel 5/6 在 1000–2000 之间漂移，那是**开关没到位/通道接错**，不是死区问题。

## 2. 失控保护链路（按触发顺序理解）

```
PPM 无脉冲 ──> RC Link Lost (COM_RC_LOSS_T) ──> NAV_RCL_ACT
                     │
                     └─ 未解锁时：预检失败，拒绝 Arm  ← 你之前踩的坑
Offboard 数据停 ──> Offboard Loss (COM_OF_LOSS_T) ──> COM_OBL_RC_ACT
打杆超阈值 ────> RC Override (COM_RC_OVERRIDE) ──> 退出 Offboard 回人工模式
```

关键结论：**"遥控器关机才能解锁"不是 bug，是预检设计。** 正确做法是让 RC 一直在线且校准通过，而不是关掉 RC 检查。

## 3. 上机核对清单（拆桨！）

1. [ ] 遥控器开机对频，QGC Radio 页能看到全部通道且回中值 ≈1500。
2. [ ] 记录 6 个开关各自对应的通道号，标注两段/三段。
3. [ ] `COM_RC_IN_MODE` 处于 RC 输入模式；RC 校准已通过。
4. [ ] 开关 A 在 Flight Modes 页绑定三档，QGC 里能看到模式随拨杆变化。
5. [ ] `RC_MAP_OFFB_SW` = 开关 B 通道号；拨到允许位，QGC 模式显示 OFFBOARD（需有 setpoint 流）。
6. [ ] 拨回常规位，模式立刻退出 Offboard。
7. [ ] 打杆测试：Offboard 中推杆能抢回（确认 `COM_RC_OVERRIDE` 位掩码是否覆盖 Offboard）。
8. [ ] 拔掉接收机（模拟 RC 丢失），确认 `NAV_RCL_ACT` 行为符合预期。
