# 长期算法路线（相机到货前能做什么）

> 目标分三层，难度递增，不要混着做：
> 1. **课程交付**：静态 / 匀速 / 部分遮挡三类场景，检测 + 跟踪 + 单目测距 + 速度闭环。
> 2. **长期-A**：人群中认出并持续跟踪**特定的人**（需要 ReID）。
> 3. **长期-B**：无 GPS 避障巡航（需要定位源 + 深度/避障传感器）。

---

## 一、当前能力与缺口

| 层 | 现在有什么 | 缺口 |
| --- | --- | --- |
| 检测 | YOLOv8n 3 头 INT8（板上 18.3 FPS 推理） | 实拍未验证；相机未到 |
| 多目标跟踪 | `vnav/mot.py`：IoU 关联 + 目标锁定；2s 遮挡保持 ID | 无外观 ReID；无相机运动补偿 |
| 遮挡处理 | 遮挡基准 0.5/1/2s + 状态机；丢失帧不返回预测 | 移动黑块/多人交叉未测 |
| 测距 | 单目 `Z=fy·H/h` | 近距离误差 ~7%；地面投影法未做 |
| 控制 | PI + 二维仿真（0.5m/s 稳态误差 0.056m） | 未上 SITL/实机；无前馈/预测 |
| 避障 | 无 | 需要深度/光流/定位，硬件未定 |

## 二、不依赖相机/飞机、现在就能写的算法

### 1. MOT + 目标锁定（已做，验证过）

`vnav/mot.py`：

- IoU 贪心关联，`tentative → confirmed → lost`；
- 恒定速度预测，短暂遮挡时 bbox 外推；
- `TargetSelector` 锁定 track_id，别的目标变大也不换；
- 丢失后按预测中心重捕获，超时才放弃；
- **丢失帧默认不返回预测框**，安全看门狗仍然能看到“目标丢失”。

验证：

- 合成轨迹：交叉、遮挡 3 帧、目标变大、丢失帧不返回预测，ID 不变
  （`tests/test_mot.py` 5/5）；
- 板上视频：无 MOT 93/120 帧有目标；MOT 安全模式 68/120（丢失帧不返回预测，
  所以数字低是预期）；预测演示 119/120，`id=1` 稳定。

**遮挡基准**（黑块挡住目标，20fps）：

| 设置 | 0.5s | 1s | 2s |
| --- | --- | --- | --- |
| `max_age=15`（旧） | 保持 | **换 ID** | **换 ID** |
| `max_age=45`（新） | 保持 | 保持 | **保持** |

> `max_age=45` 时 0.5/1/2s 都保持 `id=1`，重捕获 0 帧、ID 切换 0 次。
> 代价只是多保留 2.25s 的轨迹内存；丢失帧不输出，所以不影响安全。

**参数变更**：

| 参数 | 旧 | 新 | 依据 / 回退 |
| --- | --- | --- | --- |
| `mot_max_age` | 15 | 45 | 2s@20fps 遮挡不换 ID；回退 15 |
| `mot_max_lost` | 30 | 45 | 与 max_age 匹配；回退 30 |
| `mot_allow_predict` | — | False | 丢失不返回预测，安全优先 |

**下一版**：
- 外观直方图/OSNet embedding，遮挡后再认人；
- 相机运动补偿（用机体系速度/姿态把 bbox 平移补偿）；
- 轨迹质量分数，低质量轨迹不抢占锁定。

### 2. 遮挡状态机 + 验收基准（已做第一版）

- 合成视频：黑块挡住目标 0.5s / 1s / 2s；
- 指标：ID 保持率、重捕获时间、ID 切换次数；
- 工具：`tools/occlusion_bench.py`。

结果见上表。下一步补“移动黑块/多人交叉/遮挡后目标换方向”，
并把 `target_stale_hold_s` / `_release_s` 与 ID 保持率一起调。

### 3. 控制仿真（已做第一版）

`tools/control_sim.py`：二维运动学，目标匀速前进，复用 `TrackingMission` 的
PID/安全逻辑，不接飞控。

结果（目标 0.5m/s，保持 2.5m，10s）：

| 控制 | 稳态误差 | 末端距离 |
| --- | --- | --- |
| P-only（旧） | **0.624m** | 3.125m |
| PI（新：ki=0.3，积分限幅 2.0） | **0.056m** | 2.496m |

**参数变更**：

| 参数 | 旧 | 新 | 依据 / 回退 |
| --- | --- | --- | --- |
| `ki_distance` | 0（无积分） | 0.3 | 消除匀速目标稳态误差；回退 0 |
| `distance_integral_limit` | — | 2.0 | 太小会卡在 0.44m 误差；回退 1.0 |
| `near_slowdown_m` | 0.5 | 0.0 | 0.5 会在匀速目标下制造 ~0.5m 固定误差；回退 0.5 |

> 这是二维运动学结果，不是实飞。上机前仍要走 SITL → 拆桨 → 系留 → 低高度。

### 4. 地面投影测距（第二路距离）

单目 `Z=fy·H/h` 在近距离误差变大。加一路：

- 用 bbox 底边（人的脚）和相机安装高度/俯仰，投影到地面求距离；
- 两路融合（高度法 + 地面法），近距离优先地面法；
- 现在可以写几何 + 单测；**等相机标定后再标定俯仰/安装高度**。

### 5. ReID 接口（先留口，后换模型）

- 在 `Track` 里挂 `appearance` 字段；
- 先用 HSV 颜色直方图做“轻量重识别”，验证遮挡后重捕获；
- 相机到货/算力允许后，换 OSNet / MobileNet 的 embedding（RKNN 也能转）。

> 不要现在训 ReID：没有实拍数据，公开集与飞行画面差异大，先做接口和评估框架。

### 6. 场景生成器

- 用 COCO 图片合成：匀速平移、遮挡、交叉、远近变化；
- 作为 MOT/控制/安全逻辑的固定回归集；
- 相机到货后，用真实视频替换/补充。

## 四、已知边界（别当结论用）

- MOT 在**图像坐标系**，机体快速平移/旋转时 bbox 整体移动，IoU 关联会变差；
  实机需要把速度/姿态补偿进来，或提高帧率。
- 当前 `TargetSelector` 只按“预测中心距离”重捕获，没有外观；
  两人交叉后可能认错，这是 ReID 要解决的。
- 视频结果（安全模式 68/120、预测演示 119/120）来自合成平移视频，
  不等于真实遮挡/真实相机。
- 单目测距的距离误差仍受“人高先验”限制，不能用于精确降落。
