# 试飞版本（1m 悬停 → 加长 → 1.5m）

> 全部基于 `hover_test.py`，只是把高度/悬停时长/推力参数固定成版本，方便按顺序试。
> **每个版本飞完都会自动收尾 Land；但水平方向没有定点，会漂，必须手托/系留/空旷场地。**

## 版本表

| 版本 | 高度 | 悬停 | 推力 | kp | 目的 |
| --- | --- | --- | --- | --- | --- |
| `v1_1m_5s.sh` | 1.0m | 5s | 0.14 | 0.05 | 第一次低空悬停，确认能起、能稳、能落 |
| `v2_1m_8s.sh` | 1.0m | 8s | 0.14 | 0.05 | 加长悬停，看漂移/振荡 |
| `v3_1m_12s.sh` | 1.0m | 12s | 0.14 | 0.05 | 更长时间，看电池/热/漂移 |
| `v4_1p5m_10s.sh` | 1.5m | 10s | 0.15 | 0.04 | 稍高，确认推力/高度环余量 |
| `v5_manual_flight_log.sh` | 手动 | — | — | — | **只记录不控飞机**：遥控器手动前进/后退/转弯/降落，日志记录姿态/高度/速度 |

## 关于“前进/后退 1m、拐弯”

`hover_test.py` 只控高度，**没有 GPS/光流就没有水平位置环**，不能可靠地自动走 1m。  
周六先用 **v5 手动**做基础飞行，板子只记录；等以后加光流/GPS，再写自动平移。

## 怎么用

香橙派上：

```bash
cd ~
bash flight_tests/v1_1m_5s.sh
```

第一个版本通过后再试下一个。  
想只用 `--no-arm` 验证参数，不改脚本：

```bash
EXTRA_ARGS="--no-arm" bash flight_tests/v1_1m_5s.sh
```

端口默认 `serial:///dev/ttyACM0:115200`，需要改：

```bash
PORT=serial:///dev/ttyACM0:115200 bash flight_tests/v1_1m_5s.sh
```

## 通过标准（建议）

每个版本：

- 能正常解锁、进 OFFBOARD；
- 能到目标高度，超调不超过 ~0.3m；
- 悬停中没有明显前后/左右加速漂移（慢漂正常，但不能越漂越快）；
- 没有高频振荡；
- 打杆/拨通道 5 能接管；
- 结束后能 LAND 并自动上锁；
- USB/RC 没有掉线。

## 立即中止

- 高度超过目标 +0.5m 还在上升；
- 高频左右/前后摆；
- 明显向一个方向加速漂；
- 桨/电机异响；
- RC 接管失败；
- USB 断开 / 日志报 link lost。

## 注意

- `hover_test.py` 只控高度，**不控水平位置**；1m/1.5m 自由飞会漂，先手托/系留。
- 第一次不要直接试 `v4`；`v1 → v2 → v3` 都通过再上 1.5m。
- 电池、桨、电机转向、重心先确认。
- USB 线要固定，掉了会触发 `COM_OBL_ACT=Land`，但不要依赖它当正常收尾。
