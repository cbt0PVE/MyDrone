# 🛸 MyDrone AI 无人机视觉自主追踪项目

本项目是一个基于 **OpenCV（计算机视觉感知）**、**MAVSDK（异步上层控制）** 与 **PX4 Autopilot（开源飞控生态）** 的无人机 AI 自主控制与目标追踪系统。

项目采用“伴生电脑（Offboard）+ 底座飞控”的经典工业级软硬件解耦架构。当前阶段处于 **Mac (Apple Silicon) 仿真环境搭建与核心依赖闭环验证** 阶段。
