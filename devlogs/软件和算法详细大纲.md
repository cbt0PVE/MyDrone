## 无人机自主导航：软件与算法开发暨毕设撰写详细大纲（2026.05 - 2027.03）

## 阶段一：技术储备与仿真环境搭建（2026.05.19 - 2026.07.04）

* **阶段属性**：软硬件并行推进期（周末合体联调）
* **核心目标**：搭好电脑仿真环境，配合硬件同学完成真机首飞，打好软硬件基础。

### 1. 软件学习与个人电脑配置（周一至周五）
* **Linux 基础**：熟练掌握 Ubuntu 系统的基本操作（文件系统、SSH 远程连接、编译工具链 cmake/make）。
* **控制理论准备**：理解位置式 PID 与增量式 PID 算法的原理（输入偏差，输出速度控制量）。
* **仿真环境部署**：在个人电脑上部署 Ubuntu + ROS + PX4 Autopilot + Gazebo 仿真软件。
* **MAVSDK 跑通**：编写基础控制脚本，在 Gazebo 仿真中让虚拟无人机自主解锁、起飞、悬停 5 秒、降落。

### 2. 周末真机配合节点
* **硬件首飞配合**：全力协助硬件同学完成 Q250 机架搭建、银燕电调电机焊接以及 Pixhawk 4 的传感器校准，确保真机手动/定点首飞成功。
* **机载电脑初调**：在实验室为机载电脑刷入 Linux 系统，配置好 SSH 无线局域网连接，确保后续可以通过笔记本电脑无线控机。

## 阶段二：暑期算法攻坚与全仿真闭环（2026.07.05 - 2026.08.31）
* **阶段属性**：暑假单兵作战期（**完全不碰无人机硬件，只用个人电脑开发**）
* **核心目标**：在 Gazebo 仿真环境中，独立打通“视觉感知-运动决策-MAVSDK控制”的全流程软件闭环。

### 1. OpenCV 视觉感知算法演进（核心核心）
* **第一步：纯色物体识别（入门）**：编写代码，利用 OpenCV 进行色彩空间转换（BGR 转 HSV），通过颜色阈值分割和形态学滤波，识别并提取出目标纯色物体（如亮黄色降落垫）的中心像素坐标。
* **第二步：二维码/Aruco 标签识别（进阶）**：引入 Aruco Marker 字典，利用 OpenCV 视觉库精确识别出带有黑白矩阵特征的二维码标签，获取其在图像中的高精度像素中心点，解决纯色物体易受环境光照干扰的问题。
* **第三步：三维位姿解算（精通）**：基于单目视觉原理，利用 OpenCV 的 PnP 算法（透视三点问题求解），结合已知的 Aruco 标签实际物理尺寸，实时解算出目标物体相对于相机的三维空间相对位置（X 距离、Y 距离、Z 高度）。

### 2. 控制决策算法与仿真大联调
* **视觉 PID 控制器编写**：
    * 算法输入（误差）：目标物体的三维空间相对位置。
    * 算法输出（控制量）：将相对距离通过 PID 公式计算，转化为无人机在前后、左右、上下方向的期望飞行速度（Vx, Vy, Vz）。
* **仿真闭环大联调**：在 Gazebo 仿真环境里放置虚拟 Aruco 标签。运行代码，虚拟无人机起飞后通过虚拟相机看到标签，算法计算偏差并由 MAVSDK 下发速度指令，控制无人机自动追踪标签并完美悬停或自主降落。

## 阶段三：真机装载、相机标定与通信打通（2026.09.01 - 2026.10.15）
* **阶段属性**：开学硬件回装与单向联调期（周末合体联调）
* **核心目标**：将暑期成果移植到真机上，实现“代码控制真机飞行”与“真机视觉数据采集”。

### 1. 机载装机与通信打通（第 1-2 周周末）
* **硬件装机**：将机载电脑、相机牢固挂载在 Q250 的 3D 打印分层支架上，连接 DM02 稳压模块和串口通信线（接 Pixhawk 4 的 Telem 接口）。
* **指令测试**：真机不装桨叶进行上电安全测试。通过机载电脑运行 MAVSDK 脚本，检查能否正确读取飞控的传感器数据，并测试代码控制的自主解锁与上锁。

### 2. 相机标定与实机视觉测试（第 3-4 周周末）
* **相机张正友标定法**：在机载电脑中运行标定程序，计算相机的内参矩阵与畸变系数，消除镜头的鱼眼畸变。
* **实机 Offboard 首次起飞（第 5-6 周周末）**：手动定点起飞至 2 米，切入 Offboard 机载控制模式，由 MAVSDK 代码控制无人机水平移动 1 米并自动降落，验证代码控真机的可行性。

## 阶段四：实机全自主视觉导航闭环试飞（2026.10.16 - 2026.11.30）
* **阶段属性**：系统集成与实试飞冲刺期（周末合体联调）
* **核心目标**：把眼睛和身体结合，迎来课题的高光时刻——实机全自主视觉引导导航。

* **安全防护机制（工作日）**：编写异常处理代码。若 OpenCV 丢失目标或机载程序异常，系统必须能自动释放控制权，让遥控器可以一键切回手动挡救机。
* **手持闭环验证（周末）**：不装桨叶，手持无人机在 Aruco 标签上方晃动。如果向左晃动时电机自动加速往右对抗，证明控制算法的正负方向正确。
* **实机自主降落/追踪大考（周末）**：遥控起飞至 3 米 -> 切换至机载自主模式 -> 无人机通过摄像头搜寻地面的 Aruco 降落垫 -> 识别成功并解算三维位置 -> 视觉 PID 算法驱动无人机自主对准中心 -> 缓慢下降并在 0.3 米处锁死电机安全着陆。
